# Security policy

Found a vulnerability in figuredoutai.com or this code? Email **hello@figuredoutai.com** with the subject
"Security". Please don't open a public issue. We reply within 3 business days and credit reporters who ask.

In scope: figuredoutai.com, the waitlist and contact endpoints, the admin panel, this repository.
Out of scope: denial of service, spam, social engineering, and findings that need a compromised device.

Visitor data (waitlist sign-ups, consent records, enquiries) is stored only on the server and is never
committed to this repository. If you ever see personal data or a key in this repo, report it right away.
